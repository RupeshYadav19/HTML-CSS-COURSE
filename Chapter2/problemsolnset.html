HTML

HTML stands for HyperText Markup Language. It is the standard language used to create and structure web pages.

History

HTML was created by Tim Berners-Lee. It became an important technology for the development of the World Wide Web.

Uses

  • Creating web pages
  • Adding headings and paragraphs
  • Adding images
  • Creating links
  • Creating lists and tables
